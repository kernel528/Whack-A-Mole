# Used to track versions/releases.

Releases follow Semantic Versioning. `package.json` is the source of truth for
the current version; `index.html` displays that value through the bundled app
script. Keep this history updated when the package version changes.

* 0.1.0 - Initial Whack-a-Mole capstone starter with the game page and project assets.
* 0.2.0 - Implemented the core game flow: randomized mole appearances, scoring, and timer.
* 0.3.0 - Added the Whack-a-Hacker theme, custom styling, and optional audio assets.
* 1.0.0 - Established the initial 1.0.0 package version for the completed capstone game.
* 1.1.0 - Updated to patched Node.js 22.23.4, moved game images to local assets, migrated to Parcel 2, refreshed test dependencies, made tests choose an available port, and added a dynamic landing-page version display.
